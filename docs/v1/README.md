# Documentación de la Versión 1

Entrega del proyecto «Huertos Medicinales Comunitarios», asignatura ISWD652 Calidad de Software, período 2026B. Equipo VeliCerta.

| Archivo o carpeta | Contenido |
|---|---|
| `Proyecto-Version1-VeliCerta.pdf` (y `.docx`) | Informe de la versión 1: entregables, alcance, comparación con la definición del proyecto, arquitectura, herramientas, resultados de pruebas, incidencias y evidencia. |
| `Historias-de-Usuario-Version1-VeliCerta.pdf` | Historias de usuario HU-001 a HU-015, tal como se entregaron. |
| `Casos-de-Prueba-Version1-VeliCerta.pdf` | Casos de prueba P-001 a P-021, tal como se entregaron. La re-ejecución del 16-11-2026 está en la sección 7.3 del informe. |
| `evidencias/` | `pytest-resultados.xml` (JUnit), `pytest-salida.txt`, `cobertura.txt`, `django-check.txt`, `migraciones.txt` y `ruff-estadisticas.txt` de la ejecución del 16-11-2026. |
| `capturas/` | Capturas del producto en ejecución local, numeradas según el recorrido de las historias de usuario. |

Para ejecutar el producto y repetir las pruebas, consulta el [README del repositorio](../../README.md).
